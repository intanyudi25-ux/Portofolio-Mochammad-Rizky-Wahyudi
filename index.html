Kurikulum Cloud Computing (FS403Z)

Pilar Fundamental Cloud Architecture

Korelasi antara implementasi CloudCart HUB dengan konsep teoritis Cloud Computing yang diajarkan di Universitas Raharja.

GitHub VCS

Bertindak sebagai Source Code Management terpusat dengan integritas versi kode, branching strategy, dan webhook trigger untuk continuous integration otomatis.

Netlify PaaS

Menghilangkan beban konfigurasi server fisik (serverless edge hosting), menyediakan automated build pipeline, SSL sertifikat otomatis, dan deployment preview instan.

CDN Edge Caching

Memanfaatkan jaringan Content Delivery Network global (Tailwind, FontAwesome, Chart.js, Unsplash) guna mendistribusikan aset statis sedekat mungkin dengan pengguna.

Stateless Security

Metadata robots noindex melindungi privasi tugas akademik, dan arsitektur frontend murni mencegah celah keamanan database backend pada tahap simulasi prototipe.
